# Hướng dẫn đóng góp cho aicourse

Rất vui vì bạn muốn giúp khoá học trở nên tốt hơn! Bạn có thể đóng góp theo các cách sau:

### 1. Sửa lỗi hoặc cải thiện Code
- Hãy Fork repo này về tài khoản của bạn.
- Tạo một nhánh (branch) mới cho sự thay đổi của bạn.
- Gửi Pull Request (PR) vào thư mục `/đóng-góp/code-fixes`.

### 2. Đóng góp ý tưởng mới
- Bạn có thể tạo một file `.md` mới trong thư mục `/đóng-góp/ideas`.
- Mô tả chi tiết ý tưởng hoặc các Agent mà bạn muốn bổ sung vào khoá học.

### Lưu ý:
- Giữ code sạch sẽ, có comment giải thích để tất cả có thể cùng follow-up

> Cảm ơn mọi ý kiến đóng góp của bạn!
